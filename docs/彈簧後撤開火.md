# 彈簧後撤開火

在主選單進入「干擾決鬥」，按 **P** 或點「彈簧開火練習」。
選 **2**，點我方腳下的青色光圈：彈簧部署後，角色踩到會朝敵人的反方向短跳，落地取得一次短暫的射擊機會。
敵人會正常行動與追近，不需要時停。開火影格才判定命中並扣血。

- **R**：立即重試練習。
- **P**：回到正常對打。正常對打中同樣能使用後撤開火。
- 選彈簧時點底部的模式按鈕，或按 **Shift+2**：切換「後撤開火」和原本的「拋高下落」。練習固定使用後撤模式。
- **Tab → 彈簧開火**：觀看同一套規則的慢速拆解。

## 判定

彈射本身不造成傷害。後撤至少 64 單位，落地後才有 1.2 秒的射擊機會。
距離在 140–360、敵人位於接近高度的地面時可拔槍；開火時再次確認距離、朝向與高度。
射擊造成 2 點傷害，每次後撤最多一槍。受擊、滑倒、新的彈射或重開會清除機會。
牆邊沒有真正退開、敵人在不同樓層、開火前離開射程，都不會保證命中。

青色彈簧箭頭提示後撤方向；短暫的瞄準線、準星、槍口光、曳光與音效呈現「彈開 → 拉開距離 → 開火」。
雙方都可以踩到彈簧，要把它放在想幫助的角色腳下或路線上。

平衡數值位於 `攻擊模組 - 攻擊模組.csv` 的「後撤彈簧」與「彈簧開火」兩列。
